# 프로젝트 구조

## Backend 주요 도메인

| 도메인 | 역할 |
|---|---|
| `auth` | 회원가입, 로그인, JWT 인증 |
| `user` | 사용자 정보 관리 |
| `mission` | 탄소중립 미션 관리 |
| `verification` | QR 기반 미션 인증 |
| `point` | 탄소 감축량 관리 및 포인트 전환 |
| `partner` | 제휴처 및 직원 계정 관리 |
| `friend` | 친구 관계와 친구 기능 관리 |
| `record` | 기존 실천 데이터를 조회하고 통계 제공 |
| `home` | 홈 화면에 필요한 여러 도메인의 데이터 조회 및 조합 |
| `global` | 공통 응답, 예외 처리, 보안 설정 |

`home`은 독립적인 영속 데이터 도메인이 아니라 홈 화면에 필요한 데이터를 조회하고 조합하는 역할을 담당합니다.

`record`도 별도의 Entity나 Table을 만들지 않고, 기존 데이터를 조회해 기록과 통계를 제공합니다.

## 문서 관리

- API 상세 명세는 Swagger에서 관리합니다.
- 요구사항과 ERD는 Notion에서 관리합니다.
