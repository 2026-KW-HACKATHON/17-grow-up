# GrowUp

탄소중립 실천을 미션 형태로 기록하고, 탄소 감축량·포인트·캐릭터 성장을 통해 지속적인 친환경 실천을 돕는 서비스입니다.

## 기술 스택

### Backend

- Java 21
- Spring Boot 4.1.1
- Spring Data JPA
- Spring Security
- JWT
- MySQL
- Swagger / OpenAPI
- Gradle

### Frontend

- React
- TypeScript
- Vite

### Deployment

- Frontend: Vercel
- Backend: Railway
- Database: MySQL

## 주요 기능

- 사용자 회원가입 / 로그인
- JWT 기반 인증
- 탄소중립 미션
- QR 기반 미션 인증
- 탄소 감축량 누적
- 포인트 전환
- 캐릭터 성장
- 실천 기록 / 연속 실천
- 친구 기능
- 제휴처 및 제휴처 직원 기능
